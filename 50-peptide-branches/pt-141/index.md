# PT-141 / bremelanotide (L1)

Part of [[targeted-therapeutic-peptides]]. Brand: **Vyleesi** (subcutaneous autoinjector). Developer: Palatin Technologies (licensed to AMAG at approval).

**What it is:** a cyclic heptapeptide melanocortin-receptor agonist derived from Melanotan II (it is described as an MT-II metabolite/analogue lacking the C-terminal amide). Acts centrally, mainly via **MC4R** (also MC3R; MC1R activity explains pigmentation).

**Status (2026-11):** **FDA-approved 21 Jun 2019** for acquired, generalised hypoactive sexual desire disorder (HSDD) in **premenopausal** women, used as needed. Not approved for men, postmenopausal women, or erectile dysfunction. Not EU-authorised.

**Evidence tier: 1** — two phase 3 RCTs (RECONNECT, n≈1,267) plus a phase 2b dose-finding trial; but the effect size is **modest** (≈25% vs 17% responders on desire).
